# The New Adventures of Sonic the Hedgehog - Windows Recompiled

A native Windows recompilation of the GB Studio fangame
"The New Adventures of Sonic the Hedgehog".

## About

This project converts the original Game Boy / Game Boy Color ROM
into a native Windows executable using GB Recompiled.
